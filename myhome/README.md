# 마이홈 기록 형식

`myhome/myhome.json` — 홈페이지 마이홈 메뉴에서 가구를 눌러 남긴 기록.
컴퓨터든 폰이든 GitHub 토큰을 넣은 기기에서 기록하면 모두 이 파일 하나에 쌓여요.

```json
{
  "version": 1,
  "updated_at": "2026-11-21T15:03:10+09:00",
  "place": "부산 동구",
  "zones": ["현관", "주방", "거실", "침실", "욕실"],
  "objects": {
    "sink": { "zone": "주방", "name": "싱크대", "act": "설거지", "emoji": "🫧" }
  },
  "log": {
    "sink": {
      "2026-11-21": { "done": true, "memo": "설거지 다 함!", "at": "2026-11-21T21:40:02+09:00" }
    }
  }
}
```

| 필드 | 뜻 |
| --- | --- |
| `objects` | 가구 목록(구역, 이름, 기록하는 행동, 도장). 저장할 때마다 최신 설정으로 덮어씀 |
| `log.<가구id>.<날짜>` | 그 날의 기록. 날짜는 한국 시간 `YYYY-MM-DD` |
| `done` | 한 날이면 `true` (안 한 날은 키 자체가 없음) |
| `memo` | 그 날 메모 (없으면 키 없음) |
| `at` | 마지막으로 이 기록을 바꾼 시각 (+09:00 포함) |

리포트/통계를 만들 때는 `log`를 가구별·날짜별로 세면 돼요.
예: 이번 달 설거지 횟수 = `log.sink`에서 이번 달 날짜이면서 `done`이 `true`인 개수.
