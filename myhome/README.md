# 마이홈 기록 형식

`myhome/myhome.json` — 홈페이지 마이홈 메뉴에서 가구를 눌러 남긴 기록.
컴퓨터든 폰이든 GitHub 토큰을 넣은 기기에서 기록하면 모두 이 파일 하나에 쌓여요.

```json
{
  "version": 1,
  "updated_at": "2026-11-21T15:03:10+09:00",
  "place": "부산 동구",
  "zones": ["현관", "주방", "거실", "침실", "욕실"],
  "objects": {
    "sink": { "zone": "주방", "name": "싱크대", "act": "설거지", "emoji": "🫧" }
  },
  "log": {
    "sink": {
      "2026-11-21": { "count": 2, "done": true, "memo": "설거지 다 함!", "at": "2026-11-21T21:40:02+09:00" }
    }
  }
}
```

| 필드 | 뜻 |
| --- | --- |
| `objects` | 가구 목록(구역, 이름, 기록하는 행동, 도장). 저장할 때마다 최신 설정으로 덮어씀 |
| `log.<가구id>.<날짜>` | 그 날의 기록. 날짜는 한국 시간 `YYYY-MM-DD` |
| `count` | 그 날 한 횟수 (하루에 여러 번 가능, 0이면 키 없음) |
| `done` | 한 번이라도 했으면 `true` (`count`가 있으면 항상 같이 있음) |
| `memo` | 그 날 메모 (없으면 키 없음) |
| `at` | 마지막으로 이 기록을 바꾼 시각 (+09:00 포함) |

리포트/통계를 만들 때는 `log`를 가구별·날짜별로 세면 돼요.
예: 이번 달 설거지 횟수 = `log.sink`에서 이번 달 날짜들의 `count` 합계 (`count`가 없고 `done`만 있는 옛 기록은 1번으로 셈).

## 현관 메모

`notes` — 현관문 안쪽에 붙인 메모 목록 (여러 장).

```json
"notes": [
  { "id": "nmabc12", "title": "택배", "date": "2026-11-21", "body": "경비실에 맡겨 둠", "at": "2026-11-21T20:10:00+09:00" }
]
```

## 장바구니

`shopping` — 분리수거 옆 장바구니에 적은 장보기 목록.

```json
"shopping": [
  { "id": "smabc12", "name": "우유 2개", "tag": "마트", "done": false, "at": "2026-11-21T20:10:00+09:00" },
  { "id": "smabc13", "name": "계란", "done": true, "at": "...", "done_at": "2026-11-22T18:02:00+09:00" }
]
```

`tag`는 태그(기본: 장보기·마트·다이소·쿠팡·기타), `done`이 `true`면 산 것, `done_at`은 산 시각.
`shop_tags` — 태그 목록 (직접 추가한 태그 포함).
